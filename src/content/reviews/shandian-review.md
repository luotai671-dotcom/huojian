## 二、骨干链路架构与传输协议解析

闪电鼠的核心竞争力在于其纯正的 **IEPL（International Ethernet Private Line）企业级点对点内网专线**。

```
[用户本地客户端]
       │
       ▼ (电信 / 联通 / 移动 本地优质接入)
[BGP 多线智能入口集群 (上海/广州/北京)]
       │
       ▼ (物理隔离内网隧道，零过境公网审查)
[IEPL 端到端高速跨境内网专线]
       │
       ▼ (原生住宅与优质商业出口机房)
[海外边缘落地节点 (香港/日本/新加坡/美国)]
       │
       ▼ (直连主流目标服务集群)
[ChatGPT / Claude / Netflix / YouTube 4K]
```

### 1. 入口端调度机制
闪电鼠在国内骨干网部署了三网 BGP 动态接入入口。无论用户本地使用的是中国电信（163/CN2）、中国联通（4837/9929）还是中国移动（CMI），均能在本地或邻近省份完成就近接入，最大程度降低城域网跨网互联的延迟损耗。

### 2. 物理内网传输优势
传统普通中转服务依赖公网隧道封装，在晚高峰依然会受到国际出口公网拥塞的剧烈冲击；而闪电鼠采用的是端到端内网专线传输，数据在跨境段完全脱离公网环境，享有最高 QoS 优先级，从物理层面上杜绝了 GFW 的深度包检测（DPI）与主动探测干扰。

### 3. VLESS 与 Trojan 现代协议优化
节点全面适配基于 TLS 1.3 现代加密标准的 VLESS 与 Trojan 协议，去除了旧版协议中多余的对称加密握手包，握手往返时延（RTT）降低 40% 以上，在移动网络弱网环境下具备极强的连接保活能力。
